# 🎯 Guess The Number Game (Python)

A simple Python number guessing game where the computer randomly selects a number between **1 and 100**, and the player must guess it within a limited number of attempts.

This project is beginner-friendly and focuses on:
- Conditional logic
- Loops
- Functions
- Error handling
- Random number generation

---

## 🕹 How the Game Works

1. The program randomly chooses a number between **1 and 100**
2. The player selects a difficulty:
   - **Easy** → 10 guesses
   - **Hard** → 5 guesses
3. The player makes guesses
4. The program gives hints:
   - *Too high*
   - *Too low*
5. The game ends when:
   - The correct number is guessed ✅
   - All attempts are used ❌

---

## 🧠 Concepts Used

- `random.randint()`
- Functions
- `for` loop
- `if-elif-else`
- `try-except` for input validation
- Global variables (for learning purpose)
